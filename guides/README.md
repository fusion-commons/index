# Hands-on guides

Short, honest paths from zero to a first real fusion calculation. Each guide uses only open-source codes from [the index](../README.md), states its exact requirements, and shows the output you should expect.

1. [Your first equilibrium](your-first-equilibrium.md) — solve a free-boundary tokamak equilibrium with FreeGS. *~15 minutes.*
2. [Your first transport run](your-first-transport-run.md) — simulate five seconds of tokamak core plasma with TORAX. *~15 minutes.*
3. [Your first neutronics model](your-first-neutronics-model.md) — build and run a simple OpenMC model. *~45 minutes, including nuclear data download.*

A good order: equilibrium → transport → neutronics. That's also the shape of a real fusion design workflow.
